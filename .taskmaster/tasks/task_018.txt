Example migration guide section:

```markdown
## Migrating Existing Models to TypeScript

To migrate your existing Keystone models to TypeScript, follow these steps:

1. Create interfaces for your document data:

```typescript
interface UserData {
  name: string;
  email: string;
  isAdmin: boolean;
}

interface PostData {
  title: string;
  content: string;
  author: UserData;
  publishedDate: Date;
  status: 'draft' | 'published';
}
```

2. Use generic type parameters with your lists:

```typescript
const User = keystone.list<UserData>('User');
const Post = keystone.list<PostData>('Post');
```

3. Enjoy type-safe access to your models:

```typescript
async function getPublishedPosts() {
  const posts = await Post.model.find({ status: 'published' });
  return posts.map(post => ({
    title: post.title,
    authorName: post.author.name
  }));
}
```
